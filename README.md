# CricScorer 🏏

**Professional Offline-First Cricket Scoring & Scorecard Management PWA**

## Updates in this release (v2.3):
- **Full Settings Overhaul:**
  - Categorized into Display & Ergonomics, Match Defaults, and Local Database Health.
  - Interactive sliding toggle switches for Theme, Screen Wake Lock, and Haptics.
  - Real-time database diagnostic counts (Teams, Players, Matches, Deliveries) and storage quota.
- **Screen Wake Lock:** Prevents phone display from sleeping while on the live scoring screen.
- **Haptic Vibration:** Tactile pulse on scoring buttons, boundaries, and wickets.
- **Scorecard Dropdowns & Live Insights:** Retains live striker/non-striker/bowler switching and live match insights.
- **Clean Theme & High-Contrast 2.0 Badge:** Immediate theme toggle response and visible emerald/neon badge.
- **Modern App Icon:** Minimal, high-visibility cricket ball vector icon (`icon.svg`).

## Deploy to GitHub Pages:
1. Extract all 7 files directly into the root folder of your GitHub repository.
2. Commit and push to `main`:
   ```bash
   git add .
   git commit -m "Update CricScorer v2.3 with enhanced Settings, WakeLock, and Haptics"
   git push origin main
   ```
3. Once deployed, open your GitHub Pages link in Chrome on Android.
