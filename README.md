# CricScorer 🏏

**Professional Offline-First Cricket Scoring & Scorecard Management PWA**

## Updates in this package (v2.2):
- **Theme Switcher:** Removed duplicate event listener conflict so tapping 🌓 toggles themes immediately.
- **2.0 Badge Contrast:** High-contrast badge rendering across both Dark and Light modes.
- **Consistent App Title:** Cleaned title to "CricScorer" across manifest, metadata, and UI.
- **Minimal Icon:** Clean, high-visibility cricket ball vector icon (`icon.svg`).
- **Scorecard Dropdowns & Live Insights:** Retains live striker/non-striker/bowler on-the-fly dropdown switching and real-time match insights.

## Deploy to GitHub Pages
1. Extract files directly to the root of your repository.
2. Commit and push to `main`.
3. Open on Android in Chrome, clear site cache once, and test or re-install the PWA.
